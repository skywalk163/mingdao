# 《言律中文编程语言设计规范v1.0》

**遵循自然中文表达逻辑，兼顾严谨性与可读性的结构化编程语言**

---

## 前言

中文编程的核心痛点，从来不是「能不能用中文写代码」，而是「如何消除歧义、降低分词难度、贴合中文表达习惯，同时兼容传统编程的严谨性」。

本文整合了「双字关键字、主谓宾语序、缩进分块、原生宏系统」四大核心设计，给出一套完整可落地的中文编程语言规范，目标是：**让中文开发者用符合母语思维的方式写代码，同时保留编译型语言的严谨性与执行效率**。

---

## 第一部分 核心设计原则

### 1.1 设计目标

- **无歧义**：分词阶段即可确定语法结构，不需要NLP消歧，完全避免自然语言的多义问题
- **易学习**：贴合中文主谓宾表达习惯，不需要强行适配西方语法语序
- **可扩展**：核心关键字集精简，通过导入库、自定义宏扩展能力，避免关键字冲突
- **兼容传统**：支持传统括号、中缀表达式等成熟设计，降低开发者学习成本

### 1.2 核心约定

1. **双字关键字为主**：核心关键字全部为双字词（复合关键字由双字词组合），分词时稳定不歧义，彻底避免单字多义问题
2. **谓宾语序，管道自然**：函数调用采用「函数名在前，参数在后」的谓宾语序（函数+参数），符合中文「动词+宾语」的表达习惯；管道式调用用"然后"或"|"分隔，前一个函数的返回值自动作为后一个函数的参数
3. **缩进分块，句号可选**：采用Python风格缩进界定代码块，单行语句可省略句号，兼顾简洁性与清晰度
4. **原生支持同像性**：宏系统完全复用现有语法，代码即数据，支持编译期代码生成

## 第二部分 词法规则

### 2.1 分词规则（零NLP依赖，纯规则分词）

分词仅需三步，线性扫描即可完成，时间复杂度O(n)：

1. **预分割**：按字符类型自动分界，相邻不同类型（中文/英文数字/符号）直接切开
2. **关键字匹配**：按「先长后短」优先匹配双字核心关键字（复合关键字如「大于等于」优先匹配），剩余部分识别为标识符、数字、标点
3. **位置修正**：核心关键字仅在固定语法位置生效，非语法位置的同名标识符一律识别为变量名，彻底避免歧义

### 2.2 核心保留关键字列表

所有核心关键字均为双字词（复合关键字如「大于等于」「当满足」由双字词组合而成），不存在多义，不会和变量名冲突：

| 语法大类 | 子分类 | 关键字列表 | 语义说明 |
| --- | --- | --- | --- |
| 基础声明 | — | 定义、声明、常量、赋值、就是 | 「定义」声明变量，「常量」标记不可变，「赋值」绑定值 |
| 函数与宏 | — | 函数、参数、返回、调用、就是函、定宏、就是宏 | 「函数」声明函数，「返回」返回值，「调用」执行函数 |
| 数据类型 | — | 整数、小数、字符串、布尔、空值、数组、对象、字典 | 全部为编程领域单义词汇，无日常歧义 |
| 流程控制 | 分支 | 如果、那么、否则、可选 | 强制完整句式「如果...那么...否则...」，消除条件歧义 |
| 流程控制 | 循环 | 对于、从、到、每个、跳出、继续、结束、循环、当满足 | 「跳出」唯一对应结束循环，「当满足」对应while语义 |
| 数据操作 | — | 索引、长度 | 访问与测量数据结构 |
| 运算-算术 | — | 相加、相减、相乘、相除、取余、乘方、自增、自减 | 替代单字，彻底避免多义，明确指向运算 |
| 运算-关系 | — | 等于、不等、大于、小于、大于等于、小于等于 | 全部双字，语义唯一（复合关键字） |
| 运算-逻辑 | — | 并且、或者、非也 | 「非也」唯一表示逻辑取反，无其他含义 |
| 面向对象 | — | 类名、继承、实例、构造、方法 | 全部为编程领域明确语义，无日常歧义 |
| 异常处理 | — | 尝试、捕获、抛出、最终 | 对应try/catch/throw/finally，语义完全匹配 |
| 模块管理 | — | 导入、导出、开放 | 「导入」唯一对应引入模块，「开放」暴露接口 |
| 输入输出 | — | 输入、输出、打印、写入、读取 | 日常语义和编程语义完全统一 |

> **注**：「从」「到」为for循环句法结构字（单字），仅在 `对于...从...到...` 句式生效，不与双字关键字冲突。

### 2.3 双字运算符（语义明确，无歧义）

算术与逻辑运算符统一使用双字词，彻底避免单字多义问题：

| 运算符 | 语义 | 对应传统符号 |
| --- | --- | --- |
| 相加 | 加法 | `+` |
| 相减 | 减法 | `-` |
| 相乘 | 乘法 | `*` |
| 相除 | 除法 | `/` |
| 取余 | 取模 | `%` |
| 乘方 | 幂运算 | `**` |
| 自增 | 自增 | `++` |
| 自减 | 自减 | `--` |
| 并且 | 逻辑与 | `&&` |
| 或者 | 逻辑或 | `\|\|` |
| 非也 | 逻辑非 | `!` |
| 拼接 | 字符串拼接 | `+`（字符串） |

### 2.4 扩展关键字（非核心，需导入后使用）

扩展关键字不占用核心命名空间，需要导入对应标准库才能使用，支持用户自定义扩展：

| 扩展关键字 | 功能 | 所属模块 |
| --- | --- | --- |
| 任意 | 标记可变参数（函数/宏均可使用） | 可变参数 |
| 生成 | 宏标记输出代码片段 | 宏工具 |

> **注**：`捕获` 已升级为核心关键字（见上方「异常处理」分类）。宏系统中的「显式捕获外部变量」可直接复用核心关键字 `捕获`，通过语法位置区分异常捕获与宏变量捕获。

### 2.5 标识符命名规则

- 标识符可以由中文、英文、数字、下划线组成，不能以数字开头
- 核心关键字不能作为标识符，扩展关键字仅在导入模块后生效，不影响全局命名

### 2.6 标点与格式规则

1. **逗号(,)**：分隔参数，不能省略
2. **句号(。)**：语句终止符，单行语句可省略，多行表达式建议保留
3. **冒号(:)**：开启代码块，复合语句末尾必须加
4. **缩进**：使用4个空格（或2个空格，统一即可），缩进层级决定代码块结构
5. **换行规则**：
   - 当前行结束后，下一行缩进与当前行一致/更小 → 当前行语句结束，隐含句号
   - 当前行结束后，下一行缩进比当前行大 → 属于当前语句的代码块
   - 多行表达式拆分：换行后缩进不超过当前行，属于同一句，需要加句号结尾
6. **注释**：以`#`开头，直到行尾，支持单行注释

## 第三部分 语法规则（谓宾语序+管道式调用）

所有语句分为五类，覆盖全部编程场景，规则清晰无歧义：

### 3.1 五类基础语句形态

| 语句类型 | 结构说明 | 使用场景 | 示例 |
| --- | --- | --- | --- |
| 单独主/宾 | 仅表达式 | REPL求值、查看变量 | `x 相加 y` → 求值并输出 |
| 单独谓语 | 仅关键字/函数名 | 无参数控制流 | `跳出` → `break` |
| 谓宾结构 | 谓语（函数）+ 宾语（参数） | 函数调用、操作 | `打印 "Hello"` → `print("Hello")` |
| 主谓结构 | 主语（对象）+ 谓语（操作） | 对象自身操作、自更新 | `计数器 相加 1` → `counter += 1` |
| 主谓宾（主系表） | 主语 + 就是 + 宾语 | 定义、赋值 | `定义 x 就是 5` → `x = 5` |
| 管道调用 | 表达式 然后 函数名 | 链式处理，前者的输出作为后者的输入 | `列表 1,2,3 然后 长度` → `len([1,2,3])` |

### 3.2 谓宾语序核心规则

**函数调用采用谓宾语序**：函数名在前，参数在后，符合中文"动词+宾语"的自然表达。

**基本格式**：
- 单参数：`函数名 参数`
- 多参数：`函数名 参数1, 参数2, 参数3`

**示例**：
- `打印 "Hello"` → 等价于 `print("Hello")`
- `求和 2, 3` → 等价于 `sum(2, 3)`
- `索引 列表, 0` → 等价于 `list[0]`

### 3.3 管道式调用规则

**管道符号**：支持两种分隔符
- `"然后"` - 符合中文自然语言习惯，可读性强
- `"|"` - 简洁高效，符合编程语言惯例

**管道语义**：前一个表达式的返回值，自动作为后一个函数的第一个参数

**示例**：
```
列表 1, 2, 3 然后 长度 然后 打印
```
等价于：
```
打印(长度(列表(1, 2, 3)))
```

**执行流程**：
1. `列表 1, 2, 3` → 创建列表 `[1, 2, 3]`
2. `然后 长度` → 计算长度，得到 `3`
3. `然后 打印` → 打印结果 `3`

**管道中的函数调用**：
```
数据 | 索引 1 | 打印
```
解析为：
1. `数据` → 变量引用
2. `| 索引 1` → `索引(数据, 1)`，取第二个元素
3. `| 打印` → `打印(结果)`，打印元素

**管道规则总结**：
- 管道后的函数可以有自己的参数（附加在第一个参数之后）
- 管道自动将前一个结果插入为第一个参数

### 3.2 缩进与分块规则（句号可选，缩进优先）

**核心原则**：借鉴言律、知行、言语言的经验，采用Python风格缩进界定代码块，句号可选（非强制）。

**缩进规则**：
1. 所有复合语句（函数定义、条件、循环）必须以冒号结尾，下一行自动增加缩进开启代码块
2. 相同缩进级别的语句属于同一个代码块
3. 缩进减少自动闭合当前代码块，不需要大括号
4. 单行语句可以省略句号，换行即可
5. 多行代码块通过缩进层次自动识别边界

**示例**：

```
定义 求和 就是函 a, b：
    如果 a 大于 b 那么：
        返回 a
    否则：
        返回 b
```

解析：
- `求和`函数定义以冒号结尾，开启代码块
- `如果`语句以冒号结尾，开启内层代码块
- `否则`自动对齐到`如果`的缩进层级
- 缩进减少自动闭合代码块

**句号使用场景**：
- 单行语句：可以省略句号，换行即可
- 多语句同行：用中文句号"。"分隔（不推荐，建议每行一个语句）
- 显式结束：需要明确语句边界时可加句号

**示例对比**：

```
# 推荐：省略句号，每行一个语句
定义 x 就是 5
打印 x

# 也支持：显式句号（可选）
定义 x 就是 5。
打印 x。
```

### 3.3 表达式规则（中缀优先级，符合数学习惯）

表达式采用传统中缀写法，优先级从高到低依次为：

1. 括号：括号内表达式优先计算
2. 乘方（幂运算）
3. 相乘、相除、取余
4. 相加、相减
5. 比较运算：等于、不等、大于、小于、大于等于、小于等于
6. 非也（逻辑非）
7. 并且（逻辑与）
8. 或者（逻辑或）

示例：

- `a 相加 b 相乘 c` → `a + (b * c)`，符合数学优先级，无歧义
- `(a 相加 b) 相乘 c` → `(a + b) * c`，括号改变优先级

### 3.4 定义与赋值规则

3.4.1 变量定义

统一使用主系表结构：

`定义 变量名 就是 表达式`

示例：

`定义 计数 就是 0`\
`定义 姓名 就是 "张三"`\
`定义 数字列表 就是 数组 1,3,5,7`

3.4.2 变量赋值

变量定义后，重新赋值同样使用`就是`：

`计数 就是 计数 相加 1`

支持复合赋值省略（符合主谓规则）：

`` 计数 相加 1 → 等价于 计数 就是 计数 相加 1 → 等价于 `counter += 1` ``\
`` 计数 相减 1 → `counter -= 1` ``

### 3.5 函数定义与调用规则

3.5.1 函数定义

`定义 函数名 就是函 参数列表：`\
`    语句块`

参数列表用逗号分隔，支持默认参数：

`定义 幂运算 就是函 底数, 指数 就是 2：`\
`    返回 底数 乘方 指数`

3.5.2 函数调用（谓宾语序+管道）

**基本语法**：函数名在前，参数在后，用逗号分隔多个参数

`函数名 参数1, 参数2, 参数3`

示例：

- `幂运算 2, 3` → 等价于 `pow(2, 3)` → 结果为8
- `幂运算 2` → 等价于 `pow(2)` → 指数默认是2，结果为4
- `打印 "Hello"` → 等价于 `print("Hello")`

**管道式调用**：

```
列表 1, 2, 3 然后 长度 然后 打印
```

等价于：

```
打印(长度(列表 1, 2, 3))
```

**带参数的管道**：

```
数据 | 索引 0 | 打印
```

解析为：
1. `数据` → 变量引用
2. `| 索引 0` → `索引(数据, 0)`
3. `| 打印` → `打印(结果)`

兼容传统括号调用，适合嵌套场景：

`幂运算(2, 3)` → 和谓宾语序写法完全等价

3.5.3 可变参数函数

导入`可变参数`模块后，用`任意`标记可变参数，所有多余参数自动打包为列表：

`导入 可变参数`\
`定义 求和 就是函 任意 参数列表：`\
`    定义 结果 就是 0`\
`    对于每个 数 从 参数列表：`\
`        结果 相加 数`\
`    返回 结果`

调用时直接写任意多个参数：

`求和 1, 2, 3, 4, 5` → 结果为15，自动将1-5打包为列表传入

### 3.6 流程控制语法

3.6.1 条件分支

`如果 表达式 那么：`\
`    语句块`\
`可选 表达式 那么：`\
`    语句块`\
`否则：`\
`    语句块`

示例：

`如果 分数 大于等于 90 那么：`\
`    打印 "优秀"`\
`可选 分数 大于等于 60 那么：`\
`    打印 "及格"`\
`否则：`\
`    打印 "不及格"`

3.6.2 计数循环

`对于 循环变量 从 起始表达式 到 结束表达式：`\
`    语句块`

包含起始值，不包含结束值（和Python一致）：

`对于 i 从 0 到 10：`\
`    打印 i`

输出0-9，共10次循环。

3.6.3 遍历循环

`对于每个 元素 从 数组：`\
`    语句块`

示例：

`定义 数据数组 就是 数组 1,3,5,7`\
`对于每个 数 从 数据数组：`\
`    打印 数`

3.6.4 控制跳转

- `跳出` → `break`，跳出当前循环
- `继续` → `continue`，进入下一次循环
- `返回 表达式` → `return 表达式`，函数返回
- `返回` → 无返回值函数返回

### 3.7 数据结构语法

3.7.1 数组（列表）

定义：

`定义 数组名 就是 数组 元素1, 元素2, 元素3`

索引访问：

`` 数组名 索引 索引值 → 等价于 `list[index]` ``

获取长度：

`` 数组名 长度 → 等价于 `len(list)` ``

示例：

`定义 数据 就是 数组 5,3,8,4,2`\
`定义 第一个 就是 数据 索引 0 → 结果为5`\
`定义 个数 就是 数据 长度 → 结果为5`

3.7.2 字典

定义：

`定义 字典名 就是 字典 键1:值1, 键2:值2`

访问：

## 第四部分 宏系统设计（原生同像性，零额外学习成本）

### 4.1 核心设计原则

1. **完全复用现有语法**：宏定义和函数定义结构一致，仅关键字不同
2. **原生同像性**：宏参数直接传递AST（代码结构），不求值，输出也是AST，代码即数据
3. **默认卫生宏**：自动避免宏内部变量和外部变量冲突，不需要手动处理
4. **简单直观**：用`生成`标记输出代码，比Lisp的引号更容易理解

### 4.2 宏定义语法

`定宏 宏名 就是宏 参数列表：`\
`    语句块`\
`    生成 输出代码`

结构和函数定义完全一致，仅把`定义`改成`定宏`，`就是函`改成`就是宏`，用户不需要学习新语法。

### 4.3 核心规则

1. **参数默认不求值**：传递给宏的参数默认保留原始AST结构，编译期不求值，天然满足同像性
2. **生成标记输出**：`生成`后面的代码就是宏展开后的最终代码，宏内部参数自动替换，符合直觉
3. **默认自动卫生**：宏内部`定义`的变量自动重命名，不会和外部变量冲突，不需要用户处理
4. **显式捕获外部变量**：如果需要宏使用外部变量，在变量前加`捕获`关键字即可

### 4.4 基础宏示例

4.4.1 交换变量宏

`定宏 交换 就是宏 a,b：`\
`    生成 定义 临时 就是 a`\
`          a 就是 b`\
`          b 就是 临时`

调用：

`x, y, 交换`

编译期展开后：

`定义 临时_交换_xxxx 就是 x`\
`x 就是 y`\
`y 就是 临时_交换_xxxx`

自动重命名内部变量`临时`，不会和外部冲突，完美解决函数传值的问题。

4.4.2 n次循环宏（语法糖）

`定宏 循环n次 就是宏 次数, 代码块：`\
`    生成 对于 循环变量 从 0 到 次数 相减 1：`\

## 第六部分 实现指南

### 6.1 编译器流程

1. **分词阶段**：按本文词法规则分词，生成`INDENT/DEDENT`虚拟Token（类似Python）
2. **语法分析阶段**：按BNF生成AST，识别宏调用
3. **宏展开阶段**：遍历AST，展开所有宏，生成最终AST
4. **语义分析阶段**：类型检查、作用域检查
5. **代码生成阶段**：生成字节码或机器码，执行

### 6.2 核心难点解决

- **歧义消除**：所有歧义靠位置规则、标点、缩进提前规避，不需要语义消歧
- **分词难度**：纯规则分词，不需要NLP，几十行代码即可实现
- **宏实现难度**：仅需在语法分析后增加一次AST替换，逻辑简单，几十行代码即可实现核心功能

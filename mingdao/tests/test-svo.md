# 主谓宾语序测试

## 当前问题

输入：`2, 3, 求和, 打印`
期望输出：`(打印 (求和 2 3))`
实际输出：`(("打印" "求和") 3 2)`

## 语义分析

根据设计文档理念"把A交给B处理"：

```
2, 3, 求和, 打印
```

应该理解为管道式调用：
1. 第一步：把2和3交给`求和`处理 → `(求和 2 3)`
2. 第二步：把结果交给`打印`处理 → `(打印 (求和 2 3))`

## 关键问题

如何区分"参数"和"函数名"？

- `2` 和 `3` 是数字，明显是参数
- `求和` 和 `打印` 都是标识符，都是函数名

## 正确的解析逻辑

```
items = (2, 3, "求和", "打印")

步骤1：分离参数和函数名
- 参数：(2, 3)
- 函数名：("求和", "打印")

步骤2：从右向左应用函数
- 第一个函数（最右边）：`打印`
- 第二个函数：`求和`

步骤3：构建调用
- `求和` 应用参数：`(求和 2 3)`
- `打印` 应用结果：`(打印 (求和 2 3))`
```

## 实现思路

```racket
(define (build-svo-call items)
  ;; 分离：非字符串/字符串但不是关键字的在前，标识符在后
  (let-values ([(args funcs) (split-args-funcs items)])
    ;; 从右向左构建
    (foldr (lambda (func result)
             `(,func ,result))
           ;; 第一个函数应用所有参数
           `(,(last funcs) ,@args)
           (drop-right funcs 1))))
```

# 明道语言类型注解系统 — 设计规格

## 概述

为明道语言引入可选的**渐进类型注解**（Gradual Typing），采用 Python 风格的 `:类型` 语法，在编译时进行类型检查，不强制标注、不阻断执行。

## 语法设计

### 类型名（第一版）

| 明道类型 | 含义 | Racket 谓词 |
|---------|------|------------|
| `整数` | 整数值 | `exact-integer?` |
| `浮点数` | 浮点数值 | `(lambda (x) (and (number? x) (inexact? x)))` |
| `字符串` | 字符串 | `string?` |
| `布尔` | 布尔值 | `boolean?` |
| `空值` | 空（null） | `null?` |
| `任意` | 任意类型 | `(lambda (_) #t)` |
| `列表` | 列表（元素任意） | `list?` |
| `字典` | 哈希字典 | `hash?` |

泛型（如 `列表<整数>`）留到后续版本，需先改造 tokenizer 支持 `<` `>`。

### 变量定义

```racket
;; 带类型标注（可选）
定义 x: 整数 就是 42
定义 name: 字符串 就是 "你好"
定义 flag: 布尔 就是 真值

;; 无标注 — 自动推断为 任意
定义 x 就是 42
```

### 函数参数

```racket
;; 带参数类型
定义 add 就是函 a: 整数, b: 整数:
  返回 a 加 b

;; 混合：部分标注
定义 fn 就是函 a: 整数, b:
  返回 a 加 b
```

### 函数返回类型

```racket
;; 带返回类型（冒号分隔：参数: 类型: 返回类型: 函数体）
定义 add 就是函 a: 整数, b: 整数: 整数:
  返回 a 加 b

;; 无返回类型
定义 greet 就是函 name: 字符串:
  打印, name
```

## 类型检查架构

### 编译流程

```
源代码
  ↓ 分词器 (tokenizer.rkt) — 无变化
Token 序列
  ↓ 解析器 (parser.rkt) — 解析类型标注，嵌入 AST
带类型的 AST
  ↓ 类型检查器 (type-checker.rkt) — 新增编译时阶段
已验证的 AST
  ↓ Racket eval
执行结果
```

### 类型表示（检查器内部）

类型用 Racket symbol 表示：

```racket
'整数  '浮点数  '字符串  '布尔
'空值  '任意    '列表    '字典
```

类型环境：`(make-hasheq)`，存储变量名到类型的映射。

### 类型兼容规则

| 标注类型 | 可接受的表达式类型 |
|---------|-----------------|
| `整数` | 整数 |
| `浮点数` | 整数, 浮点数 |
| `字符串` | 字符串 |
| `布尔` | 布尔 |
| `空值` | 空值 |
| `列表` | 列表 |
| `字典` | 字典 |
| `任意` | 任意类型 |

### 类型推断

| 表达式 | 推断类型 |
|-------|---------|
| 整数字面量 | `整数` |
| 浮点数字面量 | `浮点数` |
| 字符串字面量 | `字符串` |
| 真值/假值 | `布尔` |
| 空值 | `空值` |
| 列表 [...] | `列表` |
| a 加 / 减 / 乘 / 除 b | 双方均为 `整数` → `整数`；有 `浮点数` → `浮点数` |
| a 大于 / 小于 b | `布尔` |
| 变量引用 | 查类型环境 |
| 函数调用 | 从定义环境查找返回类型，无标注则 `任意` |

### 错误报告策略

类型不匹配时**输出警告信息**（通过 `displayln` 或 `eprintf`），但**不阻止程序执行**。类似 TypeScript 的 `noEmitOnError: false` 模式。

错误信息格式：
```
类型警告: 第 N 行: 变量 'x' 标注为 整数，但实际得到 字符串
```

## 实现计划

### 文件变更

1. **新增** `mingdao/lang/type-checker.rkt` — 类型检查器核心
2. **修改** `mingdao/lang/parser.rkt` — 解析类型标注
3. **新增** `mingdao/tests/test-type-annotations.rkt` — 测试

### parser.rkt 改动

**parse-parameter-list**: 从读参数名改为读 `(名 : 类型)` 对。

```
之前: (a, b) → '(a b)
之后: (a:整数, b:字符串) → '((a 整数) (b 字符串))
```

**parse-definition**:
- 变量：读到标识符后，若下一 token 是 `:`，则读取类型名，构造 `(define 名:类型 值)` AST
- 函数：参数解析调用修改后的 `parse-parameter-list`；参数列表后若遇到 `:` 则读取返回类型，构造 `(define (名 参...) :返回类型 体)` AST

### type-checker.rkt 设计

```racket
#lang racket/base
(provide check-types)

;; 入口：遍历 AST 中的顶层表达式
(define (check-types ast [env (make-hasheq)])

;; 核心函数：
;; - infer-type expr env → 推断表达式类型
;; - check-definition expr env → 检查变量/函数定义
;; - check-function-call expr env → 检查函数调用
;; - compatible? annotated actual → 判断类型兼容性
;; - report-type-error msg → 输出类型警告
```

## 后续扩展方向

- 泛型类型：`列表<整数>`、`字典<字符串, 整数>`（需 tokenizer 支持 `<` `>`）
- 联合类型：`整数 | 字符串`
- 可选类型：`整数 | 空值`
- 函数类型：`(整数, 字符串) -> 布尔`
- 返回值类型推断（从函数体自动推断返回类型）
- 更丰富的类型错误信息（位置、上下文、修复建议）

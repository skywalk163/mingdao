# 明道语言 - 多路捕获与 finally（`尝试`/`捕获`/`始终`）设计规格

> 日期：2026-06-03
> 状态：已批准

## 1. 动机

当前 `尝试`/`捕获` 只在 tokenizer 中有关键字，parser 和运行时均未实现。需要完整的异常处理机制，支持按异常类型多路分发和 finally 收尾。

## 2. 语法

### 2.1 完整语法

```
尝试:
  <主体语句...>
捕获 <异常类型> 为 <变量>:
  <处理器语句...>
捕获 <异常类型> 为 <变量>:
  <处理器语句...>
始终:
  <收尾语句...>
```

### 2.2 各部分说明

- **尝试**：关键字，标记 try 块开始
- **捕获**：关键字，每个分支匹配一种异常类型
- **异常类型**：预定义的异常分类名称（见下方映射表）
- **为**：关键字，连接类型和绑定变量
- **变量**：在处理器中可用的异常对象
- **始终**：关键字，标记 finally 块，无论是否发生异常都会执行
- **始终**是可选的，可以只有 `尝试` + `捕获`

### 2.3 最小形式

```
尝试:
  1 除 0, 打印
捕获 任意错误 为 e:
  "出错啦", 打印
```

## 3. 异常类型映射

| 明道类型名 | Racket 谓词 | 含义 |
|---|---|---|
| `任意错误` | `exn:fail?` | 所有错误（catch-all） |
| `类型错误` | `exn:fail:contract?` | 类型/契约错误 |
| `参数错误` | `exn:fail:contract:arity?` | 参数个数错误 |
| `变量错误` | `exn:fail:contract:variable?` | 未绑定变量 |
| `文件错误` | `exn:fail:filesystem?` | 文件系统错误 |
| `读取错误` | `exn:fail:read?` | IO 读取错误 |
| `语法错误` | `exn:fail:syntax?` | 语法错误 |
| `用户错误` | `exn:fail?` | `报错` 函数触发的错误 |

## 4. 语义

1. 执行 `<主体>` 中的语句
2. 如果主体执行过程中抛出异常：
   - 从上到下依次检查每个 `<异常类型>` 是否匹配
   - 首个匹配的 `<处理器>` 被执行，`<变量>` 绑定到异常对象
   - 如果没有任何类型匹配，异常继续向外传播
3. 如果主体正常完成，跳过所有捕获分支
4. 无论主体是正常完成还是被捕获分支处理，`<收尾>` 始终执行
5. 如果 `<收尾>` 中抛出异常，替换原始异常
6. 如果捕获分支重新抛出异常，`<收尾>` 仍然执行

## 5. 编译策略

### 5.1 有 finally

```

尝试:                                          (let/ec 返回
  A                                              (with-handlers
捕获 类型错误 为 e:                                ([类型错误? (λ (e)
  B1                                                (let ([v (let ([e e]) B1)])
文件错误 为 e:                                        (始终)
  B2                                                  (返回 v))]
始终:                                              [文件错误? (λ (e)
  C                                                  (let ([v (let ([e e]) B2)])
                                                       (始终)
                                                       (返回 v))]
                                                     [exn:fail? (λ (e)
                                                       (始终)
                                                       (raise e))])
                                               (let ([v A])
                                                 (始终)
                                                 v))
```

### 5.2 无 finally

```
明道:                     Racket:
尝试:                     (with-handlers
  A                         ([类型错误? (λ (e) (let ([e e]) B1))]

  B1                        A)

  B2
```

## 7. 测试用例

### 7.1 基本捕获
```
尝试:
  1 除 0, 打印
捕获 任意错误 为 e:
  "捕获到错误", 打印
```

### 7.2 多路捕获
```
尝试:
  报错, "测试"
捕获 类型错误 为 e:
  "类型错误", 打印
捕获 用户错误 为 e:
  "用户错误", 打印
捕获 任意错误 为 e:
  "其他错误", 打印
```

### 7.3 finally
```
定义 清理标志 就是 假值
尝试:
  1 除 0, 打印
捕获 任意错误 为 e:
  "出错", 打印
始终:
  赋值 清理标志 为 真值
```

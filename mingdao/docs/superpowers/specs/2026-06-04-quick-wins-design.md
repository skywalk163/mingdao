# 明道语言快速见效三项特性设计

## 概述

为明道语言补充三项高优先级缺失功能：匿名函数短语法、字符串插值、不可变绑定。每项都是独立功能，可以按任意顺序实现。

---

## 一、匿名函数短语法（Lambda）

### 现状

目前定义函数必须命名：

```racket
定义 fn 就是函 a, b: 返回 a 加 b
```

无法内联定义匿名函数，导致 `映射`、`过滤` 等操作必须提前命名函数。

### 语法

```racket
匿名函数 参数列表: 表达式
```

### 示例

```racket
;; 单参数
匿名函数 x: x 加 1

;; 多参数
匿名函数 a, b: a 加 b

;; 内联使用
映射 匿名函数 x: x 加 1, [1, 2, 3]

;; 赋值给变量
定义 add 就是 匿名函数 a, b: a 加 b

;; 多语句（用 开始...结束 块）
匿名函数 x: 开始
  打印 x
  返回 x 加 1
结束
```

### 语义

| 特性 | 行为 |
|------|------|
| 单表达式 | 自动返回表达式的值，无须 `返回` |
| 多语句 | 必须用 `返回` 显式返回值 |
| 参数数量 | 支持 0-N 个参数 |
| 无默认参数 | 暂不支持参数默认值 |
| 闭包 | 捕获外层变量（Racket 的 λ 天然支持） |

### 内部表示

解析为 Racket 的 `(λ (参数...) 体)`。

```
匿名函数 x: x 加 1  →  (λ (x) (+ x 1))
匿名函数 a, b: a 加 b  →  (λ (a b) (+ a b))
```

### 实现变更

- **tokenizer**：新增关键字 `匿名函数`、`开始`、`结束`（如尚未注册）
- **parser**：新增 `parse-anonymous-function` 分支，处理 `匿名函数 参数: 体`
  - 在 `parse-atomic-expression` 中新增 `KEYWORD "匿名函数"` 分支
  - 读取参数列表（同 `parse-parameter-list`）
  - 读取冒号后的体表达式
  - 单表达式模式：体是一个表达式
  - 多语句模式：遇到 `开始` 进入块，跨过 N 行后遇到 `结束` 终止

## 二、字符串插值

### 现状

只能通过 `拼接` 拼接字符串：

```racket
"你好" 拼接 name 拼接 "!"
```

冗长且不可读。

### 语法

```racket
f"... {表达式} ..."
```

与 Python 的 f-string 一致。`f` 后紧跟 `"` 开头双引号字符串。

### 示例

```racket
定义 name 就是 "小明"
f"你好 {name}"                ;; → "你好 小明"
f"1 + 1 = {1 加 1}"           ;; → "1 + 1 = 2"
f"价格: {价格}元"              ;; → "价格: 99元"
f"转义 {{字面大括号}}"         ;; → "转义 {字面大括号}"
```

### 语义

| 特性 | 行为 |
|------|------|
| 触发符 | `f"` 前缀（`f` 后紧跟 `"`） |
| 插值标记 | `{表达式}`，运行时求值并调用 `~a` (display) 转字符串 |
| 转义 `{` | `{{` → 字面 `{` |
| 嵌套 | 不支持嵌套 f-string |
| 多行 | 不支持多行 f-string |

### 内部表示

在 tokenizer 层面展开为 `(string-append ...)` 调用。

```
f"你好 {name}"  →  (string-append "你好 " (~a name))
f"a{b}c{d}"    →  (string-append "a" (~a b) "c" (~a d))
```

### 实现变更

- **tokenizer**：在 `read-string` 或主循环中，检测到 `f"` 前缀时进入 f-string 模式
  - 逐字符读取，遇到 `{` 时切分子串
  - 嵌套 `{...}` 需要计数配对
  - 返回一个新的 token 类型（或展开为 AST 片段）
- **parser**：解析 f-string token，在 AST 层面展开为 `(string-append ...)`

## 三、不可变绑定

### 现状

所有变量都是可变的：

```racket
定义 x 就是 42
赋值 x 为 100          ;; ✅ 可以随意修改
```

需要一种不可变声明，防止意外修改变量。

### 语法

```racket
常量 变量名 就是 值
常量 变量名: 类型 就是 值
```

### 示例

```racket
常量 x 就是 42          ;; 不可变
x 就是 43               ;; → 编译时错误（解析阶段）

定义 y 就是 100         ;; 可变
赋值 y 为 101           ;; ✅

常量 name: 字符串 就是 "hello"   ;; 支持类型标注
```

### 语义

| 特性 | 行为 |
|------|------|
| 声明方式 | `常量 变量 就是 值` |
| 可变性 | 后续任何 `赋值 变量 为 ...` 都被禁止 |
| 类型标注 | 支持现有 `: 类型` 语法 |
| 作用域 | 与 `定义` 相同（当前块级作用域） |
| 允许多次声明 | 同 `定义`，允许同名覆盖（不抛出错误） |

### 实现变更

- **tokenizer**：新增关键字 `常量`
- **parser**：新增 `parse-constant` 分支或修改 `parse-definition`
  - `常量` 与 `定义` 共享大部分解析逻辑
  - AST 新增 `(常量 name value)` 节点
  - 或者简单地包装为 `(define name value)` + 元数据标记
- **编译器/求值器**：在 core.rkt 中处理 `(常量 ...)` 时，检查后续是否有 `set!` 操作
  - 可以通过在 `赋值` 语句中检查变量是否被注册为不可变来实现

---

## 实现顺序

建议按以下顺序实现：

1. **匿名函数** — 独立功能，不影响其他解析逻辑
2. **字符串插值** — 独立的 tokenizer 变更
3. **不可变绑定** — 涉及 parser + core.rkt 变更

每个功能完成后应立即运行现有测试套件，确保无回归。

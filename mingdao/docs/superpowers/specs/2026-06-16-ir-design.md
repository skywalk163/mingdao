# M6 — SSA IR 与优化设计规格

明道语言中间表示（Intermediate Representation）设计文档。

## 1. 目标

1. 在 AST 和 Racket 求值之间插入一层 **SSA（Static Single Assignment）IR**
2. 基于 IR 实现经典的标量优化：常量折叠、死代码消除、公共子表达式消除（CSE）、函数内联
3. 将优化后的 IR **降级（emit）** 为 Racket 代码，保持与现有运行时的兼容性
4. 为未来的 AOT 编译/机器码生成预留接口

## 2. 整体管道

```
AST (from parser) → Lowering → SSA IR → Optimizations → Emitting → Racket code
     ↑                                        ↑
     │ 语义分析器 (semantic.rkt)              │ 类型信息
     │ 类型检查器 (type-checker.rkt)          │ 用于 emit
     └────────────────────────────────────────┘
```

**新模块：** `lang/ir.rkt`（IR 定义 + Lowering + 优化 + Emitting）

**新测试：** `tests/test-ir.rkt`（IR 测试）

## 3. IR 数据结构

### 3.1 值（Values）

所有值都携带类型信息。

```
ir-value (type)
  ├── ir-const (value)          字面常量（数字/字符串/布尔/空）
  ├── ir-var (name)             SSA 虚拟变量（只读，只赋值一次）
  └── ir-label (name)           基本块标签
```

### 3.2 指令（Instructions）

```
ir-instr (result)              result 是可选的 ir-var（目标变量）
  ├── ir-assign (source)        %n = value
  ├── ir-load (var-name)        %n = load <mutable-var>
  ├── ir-store (var-name value) store <value>, <mutable-var>
  ├── ir-binop (op left right)  %n = op(left, right)   op: '加'/'减'/'乘'/'除'/'模'/'幂'
  ├── ir-unop (op operand)      %n = op(operand)        op: '非'/'负'/'长度'
  ├── ir-cmp (op left right)    %n = cmp(left, right)   op: '大于'/'小于'/'等于'/'不等'/'大于等于'/'小于等于'
  ├── ir-call (fn args)         %n = call(fn, args...)
  ├── ir-phi (edges)            %n = phi((label1, val1), (label2, val2), ...)  ← SSA 核心
  │
  └── 终结指令（控制流）
       ├── ir-ret (value)        return value
       ├── ir-br (target)        goto target
       └── ir-cond-br (cond then-label else-label)   if(cond) goto A else goto B
```

### 3.3 基本块（Basic Block）

```
ir-block (label instrs terminator)
  - label: ir-label         块标签（用作 goto 目标）
  - instrs: list[ir-instr]  普通指令序列（phi 节点必须在开头）
  - terminator: ir-instr    终结指令（ret/br/cond-br），不可为空
```

**基本块不变式：**
1. 块内的 phi 节点必须在普通指令之前
2. 每个块必须有且仅有一个终结指令
3. 终结指令只能出现在块的最后

### 3.4 函数（Function）

```
ir-function (name params return-type blocks)
  - name: string            函数名
  - params: list[ir-var]    参数列表
  - return-type: symbol     返回类型
  - blocks: list[ir-block]  基本块列表，第一个是入口块
```

### 3.5 模块（Module）

```
ir-module (functions globals)
  - functions: list[ir-function]   函数列表
  - globals: hash[name → type]     全局变量表
```

## 4. Lowering 过程（AST → SSA IR）

### 4.1 Lowering 状态

```
lower-state:
  - current-block: ir-block         当前正在构建的块
  - blocks: list[ir-block]          已完成的块
  - var-counter: integer            虚拟变量计数器（%0, %1, ...）
  - label-counter: integer          基本块标签计数器（B0, B1, ...）
  - mutable-vars: hash[name → ir-var]   可变变量映射（对应 set!/=）
  - fn-name: string                 当前函数名
```

### 4.2 Lowering 规则（每个 AST 节点）

| AST 形式 | Lowering 结果 |
|---------|--------------|
| 数字/字符串/布尔常量 | `ir-const` |
| 符号引用（不可变） | `ir-var` 查 SSA 名 |
| 符号引用（可变变量） | `ir-load` + 产生 ir-var |
| `(define var value)` | 对 value lowering → ir-store |
| `(set! var value)` | 对 value lowering → ir-store |
| `(= var value)` | 同上 |
| `(op a b)` | 对 a 和 b 分别 lowering → ir-binop |
| `(if cond then else)` | 产生 then-block, else-block, merge-block；在 merge-block 放 phi |
| `(for ...)` | 展开为 while 循环：init-block → head-block → body-block → update-block → head-block |
| `(return val)` | ir-ret |
| `(fn arg1 arg2 ...)` | 对 args lowering → ir-call |
| `(define (fn params) body)` | 产生新的 ir-function，对 body lowering |

### 4.3 SSA 构建关键点

**Phi 节点插入位置**：每次 if/for 等控制流合并处，在合并块的开头插入 phi 节点。

```
示例：(if (> x 0) (set! y 1) (set! y -1))
```
```
入口块：
  %0 = load x
  %1 = cmp 大于 %0, 0
  cond-br %1, B1, B2

B1 (then):
  %2 = const 1
  store %2, y
  br B3

B2 (else):
  %3 = const -1
  store %3, y
  br B3

B3 (merge):
  %4 = phi((B1, %2), (B2, %3))   ; 合并 y 的值
  ...继续...
```

## 5. 优化 Passes

### 5.1 常量折叠（Constant Folding）

对 `ir-binop` 两个操作数都是 `ir-const` 的情况，直接计算结果。

```
before: %2 = 加 %0, %1    where %0 = const 3, %1 = const 4
after:  %2 = const 7
```

### 5.2 死代码消除（Dead Code Elimination, DCE）

从 ret/分支的终点反向标记「使用到」的指令，未被标记的指令删除。

1. 从终结指令开始，收集所有「活」值
2. 反向遍历指令，将结果变量是「活」的指令加入活集合
3. 删除所有不在活集合中的指令

### 5.3 公共子表达式消除（Common Subexpression Elimination, CSE）

维护一个表达式哈希表，相同的 `(op, left, right)` 复用同一结果。

```
before: %2 = 加 %0, %1
        %5 = 加 %0, %1    ← 与 %2 相同
after:  %2 = 加 %0, %1
        %5 = %2           ← 赋值别名（或直接替换所有 %5 使用为 %2）
```

### 5.4 函数内联（Inlining）

对满足以下条件的函数调用进行内联：
- 函数体较小（指令数 ≤ 20）
- 是当前模块内的函数
- 没有递归调用

将被调函数的基本块复制到调用处，参数用实参替换，返回值用 phi 合并。

### 5.5 Pass 执行顺序

```
Lowering → 常量折叠 → CSE → 死代码消除 → 内联 → 再次常量折叠+DCE → Emitting
```

## 6. Emitting 过程（IR → Racket）

将优化后的 IR 翻译回 Racket S-表达式。

### 6.1 基本策略

由于 Racket 本身是高级语言，SSA 的虚拟变量和 phi 节点可以直接翻译为 Racket 的 `let` 绑定。

```
%1 = const 3                    → (define %1 3)
%2 = 加 %0, %1                  → (define %2 (+ %0 %1))
cond-br %2 B1 B2                → (if %2 (goto B1) (goto B2))
phi((B1, %2), (B2, %3))         → (define %4 (if <used-B1?> %2 %3))
```

**简化方案**：对于没有复杂循环/phi 的情况，直接用 let 链。对于有 phi 的情况，用 `letrec` 或条件表达式显式表达。

### 6.2 控制流翻译

- 基本块 → `let` 形式的代码块，标签用 gensym 产生
- `br` → 参数化函数调用（trampoline 形式）
- `cond-br` → `if` + 函数调用
- `ret` → 返回值

```racket
;; 对于简单情况，直接翻译为 if/let 形式的普通 Racket
(define (fn-name params)
  (let* ([%0 (value-0)]
         [%1 (value-1)]
         [%2 (op %0 %1)])
    (if %2
        (then-block)
        (else-block))))
```

### 6.3 可变变量翻译

`ir-load`/`ir-store` 对应 Racket 的变量读写。如果变量被 store，则用 `box`/`unbox` 模拟可变引用；否则用普通 `let` 绑定。

## 7. 与现有管道的集成

### 7.1 reader.rkt 的改动

```racket
;; 原流程: tokens -> AST -> semantic errors -> (module ... Racket code)
;; 新流程: tokens -> AST -> semantic errors -> type-check -> IR -> optimize -> emit -> (module ...)

(define (analyze->ir ast builtin-names)
  (let* ([semantic-errors (analyze ast builtin-names)]
         [ir (lower-module ast builtin-names)]
         [optimized-ir (optimize-module ir)]
         [racket-code (emit-module optimized-ir)])
    (values semantic-errors racket-code)))
```

### 7.2 兼容性

- **开关控制**：`(define use-ir-optimization? #t)` 可切换启用/禁用
- 禁用时走原路径：直接把 AST 包装为 `(module ...)`
- 启用时走 IR 路径，但对外行为一致（相同输入产生相同输出）

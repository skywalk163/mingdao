# M6 严格类型系统 2.0 设计文档

## 1. 概述

M6 严格类型系统 2.0 是明道语言的核心升级，提供编译时和运行时的严格类型检查，支持泛型、接口、类型推断等现代类型系统特性。

### 设计目标

| 目标 | 描述 |
|------|------|
| **严格模式** | 类型不匹配时抛出编译错误而非警告 |
| **泛型支持** | 泛型类型参数、约束、类型推断 |
| **接口系统** | 定义接口类型和实现约束 |
| **智能推断** | 基于数据流的类型推断 |
| **类型安全** | 运行时严格类型校验 |

## 2. 类型系统架构

### 2.1 类型表达式语法

```
类型表达式:
  基础类型 | 泛型类型 | 联合类型 | 类型别名 | 接口类型

基础类型:
  整数 | 浮点数 | 字符串 | 布尔 | 空值 | 任意

泛型类型:
  类型名<类型参数列表>
  
联合类型:
  类型表达式 \| 类型表达式  (PIPE 语法)
  类型表达式 或 类型表达式 (中文语法)

类型参数列表:
  类型表达式 [, 类型表达式]*
```

### 2.2 类型层次结构

```
                    任意
                      |
        +-------------+-------------+
        |             |             |
     数值           序列           复合
        |             |             |
   +----+----+    列表<T>      字典<K,V>
   |         |    数组<T>      结构<T>
  整数     浮点数               接口<T>
```

### 2.3 核心数据结构

```racket
;; 类型表达式结构
(struct type-expr () #:transparent)
(struct type-base type-expr (name) #:transparent)     ; 基础类型
(struct type-param type-expr (name) #:transparent)    ; 类型参数
(struct type-generic type-expr (name args) #:transparent)  ; 泛型类型
(struct type-union type-expr (types) #:transparent)   ; 联合类型
(struct type-interface type-expr (name methods) #:transparent)  ; 接口类型
(struct type-alias type-expr (name target) #:transparent)  ; 类型别名

;; 类型环境
(struct type-env (vars    ; 变量类型表 (name → type-expr)
                  fns     ; 函数签名表 (name → (list params return-type))
                  types   ; 类型别名表 (name → type-expr)
                  ifaces  ; 接口表 (name → interface-def)
                  generic-constraints))  ; 泛型约束表
```

## 3. 核心功能设计

### 3.1 严格模式

**设计要点：**
- 在编译阶段进行严格类型检查
- 类型不匹配时抛出 `exn:fail:type` 异常
- 支持通过 `#lang mingdao/strict` 或 `#lang mingdao/relaxed` 选择模式

**错误类型：**

| 错误类型 | 场景 | 示例 |
|---------|------|------|
| `类型不匹配` | 赋值类型不一致 | `定义 x: 整数 就是 "字符串"` |
| `参数类型错误` | 函数调用参数类型错误 | `fn("abc")` 但期望整数 |
| `返回类型错误` | 返回值类型与声明不符 | `返回 "str"` 但声明返回整数 |
| `类型未定义` | 引用未定义的类型 | `定义 x: MyType 就是 1` |
| `泛型参数缺失` | 泛型类型缺少类型参数 | `定义 xs: 列表 就是 [1]` |

### 3.2 泛型增强

**泛型类型定义语法：**

```mingdao
;; 泛型函数
定义 映射 就是函 T:
    xs: 列表<T>, fn: 函数<T -> R>:
  列表
  对于 x 在 xs:
    追加 (fn, x)

;; 泛型类型别名
定义类型 Option<T> 就是 T | 空值

;; 泛型约束
定义 比较 就是函 T: 可比较:
    a: T, b: T: 布尔:
  返回 a 大于 b
```

**泛型约束类型：**

| 约束 | 描述 | 内置实现 |
|------|------|----------|
| `可比较` | 支持比较操作 | 整数、浮点数、字符串 |
| `可哈希` | 支持哈希运算 | 所有基本类型 |
| `可调用` | 支持函数调用 | 函数类型 |
| `可迭代` | 支持迭代 | 列表、字符串 |

### 3.3 接口/协议系统

**接口定义语法：**

```mingdao
;; 定义接口
定义接口 可打印:
  方法 转字符串 -> 字符串

;; 实现接口
定义类 人 实现 可打印:
  字段 名字: 字符串
  方法 转字符串 -> 字符串:
    返回 "人: " 拼接 名字

;; 接口约束
定义 打印所有 就是函 T: 可打印:
    items: 列表<T>:
  对于 item 在 items:
    item, 转字符串, 打印
```

**接口特性：**
- 接口方法签名（名称、参数类型、返回类型）
- 接口继承（一个接口可以继承多个接口）
- 结构类型匹配（duck typing 风格）

### 3.4 类型推断增强

**推断策略：**

1. **数据流推断**：基于赋值语句推断变量类型
2. **上下文推断**：根据使用上下文推断类型
3. **约束求解**：解决类型等式约束

**推断示例：**

```mingdao
;; 自动推断 x 为整数
定义 x 就是 42

;; 根据返回语句推断函数返回类型
定义 加一 就是函 n:
  返回 n 加 1

;; 根据参数使用推断类型
定义 处理 就是函 items:
  第一个 = items, 索引 0    ; items 推断为列表类型
  返回 第一个

;; 泛型参数推断
定义 xs 就是 [1, 2, 3]    ; 推断为 列表<整数>
```

### 3.5 类型安全保障

**运行时类型校验：**
- 在函数边界进行类型检查
- 在类型转换时进行校验
- 提供 `断言类型` 内置函数

**类型转换规则：**

| 源类型 | 目标类型 | 允许 | 转换方式 |
|--------|----------|------|----------|
| 整数 | 浮点数 | 是 | 自动转换 |
| 浮点数 | 整数 | 是 | 截断警告 |
| 字符串 | 整数 | 是 | 解析转换 |
| 任意 | 具体类型 | 是 | 运行时校验 |
| 列表 | 字符串 | 否 | - |

## 5. 语法扩展

### 5.1 新语法特性

| 语法 | 用途 | 示例 |
|------|------|------|
| `定义类型` | 类型别名 | `定义类型 MyInt 就是 整数` |
| `定义接口` | 接口定义 | `定义接口 可打印:` |
| `实现` | 实现接口 | `定义类 X 实现 I:` |
| `->` | 函数返回类型箭头 | `定义 fn -> 整数:` |
| `|` | 联合类型 | `定义 x: 整数 | 字符串` |

### 5.2 类型标注语法增强

```mingdao
;; 变量标注
定义 x: 整数 就是 42
定义 name: 字符串 就是 "小明"

;; 函数标注（简化语法）
定义 fn: (整数, 整数) -> 整数 就是函 a, b:
  返回 a 加 b

;; 泛型标注
定义 xs: 列表<整数> 就是 [1, 2, 3]
定义 d: 字典<字符串, 整数> 就是 字典 "a": 1

;; 联合类型标注
定义 v: 整数 | 字符串 | 空值 就是 空值

;; 接口标注
定义 p: 可打印 就是 新建 人 "张三"
```

## 6. 类型检查流程

```
源代码 → Tokenize → Parse → Type Check → IR → Optimize → Emit
                             ↓
                    类型环境构建
                    类型推断
                    类型兼容性检查
                    错误报告
```

### 6.1 类型检查阶段

1. **类型环境初始化**：加载内置类型、接口、函数签名
2. **类型别名解析**：展开所有类型别名
3. **泛型实例化**：处理泛型类型参数
4. **表达式类型推断**：对每个表达式推断类型
5. **兼容性检查**：验证类型标注与推断结果匹配
6. **错误收集与报告**：汇总所有类型错误

## 7. 向后兼容性

由于用户明确要求"不兼容"，本设计不保证与旧代码的兼容性。升级策略：

1. **逐步迁移**：提供迁移工具检测类型问题
2. **模式选择**：支持 `#lang mingdao/strict` 和 `#lang mingdao/relaxed`
3. **错误提示**：提供清晰的迁移指南和错误提示

## 9. 性能考虑

1. **增量类型检查**：只检查修改的部分
2. **缓存类型信息**：避免重复计算
3. **编译时优化**：移除运行时类型检查代码
4. **并行检查**：可并行处理独立的类型检查任务

---

## 10. 安全考虑

1. **类型混淆防护**：防止通过类型转换绕过安全检查
2. **运行时类型校验**：确保外部输入的类型安全
3. **错误信息安全**：避免泄露敏感信息

# 明道语言生成器/yield 特性设计

## 概述

为明道语言添加惰性序列生成器支持，允许使用 `产出` 关键字创建可迭代的生成器函数。

---

## 一、生成器特性

### 现状

目前只能使用 `列表` 创建立即求值的序列：
```racket
列表 1, 2, 3              ;; → (1 2 3) 立即求值
```

无法创建惰性序列，导致处理大数据集时内存压力大。

### 语法

```racket
定义 生成器函数名 就是函 参数列表:
  产出 表达式
  产出 表达式
  ...
```

### 示例

```racket
;; 基础生成器
定义 count 就是函 n:
  产出 n
  产出 n 加 1
  产出 n 加 2

;; 无限生成器
定义 自然数 就是函:
  定义 i 就是 0
  对于 永真:
    产出 i
    赋值 i 为 i 加 1

;; 使用生成器
定义 gen 就是 count, 10
取第一个, gen        ;; → 10
取第一个, gen        ;; → 11
取第一个, gen        ;; → 12

;; 转换为列表
转换列表, count, 1   ;; → (1 2 3)
```

### 语义

| 特性 | 行为 |
|------|------|
| `产出` | 暂停函数执行，返回值给调用者 |
| 再次调用 | 从上次产出位置继续执行 |
| 函数结束 | 返回序列结束标记 |
| 参数 | 支持任意参数（同普通函数） |
| 闭包 | 捕获外层变量 |

### 内部表示

```racket
;; 生成器函数定义
定义 gen 就是函 x:
  产出 x
  产出 x 加 1

;; 编译为 Racket 的 generator 形式
(define gen
  (generator ()
    (yield x)
    (yield (+ x 1))))

;; 使用生成器
(gen)   ;; → x
(gen)   ;; → (+ x 1)
(gen)   ;; → eof
```

### 配套函数

| 函数 | 说明 |
|------|------|
| `取第一个` | 获取生成器的下一个值 |
| `转换列表` | 将生成器转换为列表 |
| `取前N个` | 获取前 N 个元素 |
| `生成器?` | 判断是否为生成器 |

---

## 二、实现变更

### 1. Tokenizer

- 添加关键字 `"产出"` 到 `控制流关键字`

### 2. Parser

- 在 `parse-definition` 中检测函数体是否包含 `产出`
- 如果包含，生成 `(generator () ...)` 形式的 AST

### 3. Core.rkt

- 添加生成器相关的运行时支持函数

### 4. 测试

- 创建 `test-generator.rkt` 测试文件

---

## 三、实现步骤

1. **Tokenizer**：添加 `"产出"` 关键字
2. **Parser**：检测函数体中的 `产出` 语句，生成 generator AST
3. **Core.rkt**：添加运行时支持
4. **测试**：编写测试用例

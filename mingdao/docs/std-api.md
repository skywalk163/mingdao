## JSON 模块

文件：`std/json.rkt`

提供 JSON 数据的解析和生成功能。

### 函数

| 函数 | 参数 | 描述 |
|------|------|------|
| `json解析` | `input-str` | 将 JSON 字符串解析为 Racket 数据结构 |
| `json生成` | `value` | 将 Racket 数据结构生成为 JSON 字符串 |
| `json字符串转列表` | `input-str` | `json解析` 的别名 |
| `列表转json字符串` | `value` | `json生成` 的别名 |
| `json/从文件读取` | `path` | 从文件读取并解析 JSON |
| `json/写入文件` | `value, path` | 将数据写入文件为 JSON |
| `解析json` | `input-str` | `json解析` 的别名 |
| `生成json` | `value` | `json生成` 的别名 |
| `json转列表` | `input-str` | `json解析` 的别名 |
| `列表转json` | `value` | `json生成` 的别名 |
| `json读文件` | `path` | `json/从文件读取` 的别名 |
| `json写文件` | `value, path` | `json/写入文件` 的别名 |
| `读取json文件` | `path` | `json/从文件读取` 的别名 |
| `写入json文件` | `value, path` | `json/写入文件` 的别名 |

### 示例

```racket
(require "std/json.rkt")

(json解析 "{\"name\":\"明道\",\"version\":1}")
;; → '#hash(("name" . "明道") ("version" . 1))

(json生成 #hash(("lang" . "Racket") ("year" . 2025)))
;; → "{\"lang\":\"Racket\",\"year\":2025}"

(json/从文件读取 "data.json")
(json/写入文件 '("hello" "world") "output.json")
```

## CSV 模块

文件：`std/csv.rkt`

提供 CSV 格式数据的解析和生成。

### 函数

| 函数 | 参数 | 描述 |
|------|------|------|
| `csv解析` | `str` | 将 CSV 字符串解析为列表的列表（每行为一个列表） |
| `csv读取` | `path` | 从文件读取并解析 CSV |
| `csv生成` | `rows` | 将列表的列表生成为 CSV 字符串 |
| `csv写入` | `path, rows` | 将数据写入文件为 CSV |

### 示例

```racket
(require "std/csv.rkt")

(csv解析 "a,b,c\n1,2,3")
;; → '(("a" "b" "c") ("1" "2" "3"))

(csv生成 '(("姓名" "年龄") ("张三" "28") ("李四" "35")))
;; → "姓名,年龄\n张三,28\n李四,35"
```

## RE 正则模块

文件：`std/re.rkt`

提供正则表达式操作函数。

### 函数

| 函数 | 参数 | 描述 |
|------|------|------|
| `正则搜索` | `模式, 字符串` | 搜索匹配，返回匹配结果列表或空列表 |
| `正则匹配` | `模式, 字符串` | 判断是否匹配，返回布尔值 |
| `正则替换` | `模式, 字符串, 替换串` | 替换第一个匹配项 |
| `正则全部替换` | `模式, 字符串, 替换串` | 替换所有匹配项 |
| `正则分割` | `模式, 字符串` | 按模式分割字符串 |
| `正则匹配所有` | `模式, 字符串` | 返回所有匹配的子串 |
| `正则转义` | `字符串` | 转义字符串中的正则特殊字符 |
| `正则编译` | `模式` | 编译正则表达式（支持字符串或已有正则） |
| `正则匹配位置` | `模式, 字符串` | 返回所有匹配的位置 \[(start . end)\] |

### 示例

```racket
(require "std/re.rkt")

(正则搜索 "\\d+" "abc123def")       ;; → '("123")
(正则匹配 "\\d+" "abc123def")       ;; → #t
(正则替换 "\\d+" "a1b2c3" "X")     ;; → "aXb2c3"
(正则全部替换 "\\d+" "a1b2c3" "X")  ;; → "aXbXcX"
(正则分割 "[,;]" "a,b;c")           ;; → '("a" "b" "c")
(正则转义 "a.b")                    ;; → "a\\.b"
```

| 函数 | 参数 | 描述 |
|------|------|------|

### 示例

```racket
(require "std/datetime.rkt")

(今天)                        ;; → "2026-06-03"
(日期/创建 2025 1 15)         ;; → "2025-01-15"
(日期/差 "2025-01-10" "2025-01-15")  ;; → 5
(日期/加 "2025-01-28" 3)      ;; → "2025-01-31"
(现在)                        ;; → "2026-06-03 14:30:00"
(天数 2024 2)                 ;; → 29（闰年）
```

| `计数器/最多` | `counter, [n]` | 返回频次最高的 n 项（按降序） |
| `计数器/相加` | `c1, c2` | 两个计数器合并（频次相加） |
| `计数器/相减` | `c1, c2` | 两个计数器相减（频次相减） |

### Deque（双端队列）

|------|------|------|
| `双端队列/创建` | `...items` | 创建双端队列 |
| `双端队列/左追加` | `dq, item` | 左侧追加元素 |
| `双端队列/右追加` | `dq, item` | 右侧追加元素 |
| `双端队列/左弹出` | `dq` | 左侧弹出元素，返回 (新队列, 元素) |

| `双端队列/左扩展` | `dq, items` | 左侧扩展多个元素 |
| `双端队列/旋转` | `dq, [n]` | 向右旋转 n 步（默认 1） |

### defaultdict（默认字典）

| 函数 | 参数 | 描述 |
|------|------|------|
| `默认字典/创建` | `fn` | 创建默认字典，不存在的键由 fn 生成默认值 |
| `默认字典/获取` | `dd, key` | 获取值（不存在时自动创建默认值） |

### OrderedDict（有序字典）

| 函数 | 参数 | 描述 |
|------|------|------|
| `有序字典/创建` | — | 创建空有序字典 |
| `有序字典/获取` | `od, key, [default]` | 获取值 |
| `有序字典/设置` | `od, key, val` | 设置键值对（保持插入顺序） |
| `有序字典/转为列表` | `od` | 转为 (key . val) 的关联列表 |

### namedtuple（命名元组）

| 函数 | 参数 | 描述 |
|------|------|------|
| `命名元组/创建` | `name, ...fields` | 创建一个命名元组类型 |
| `命名元组/新建` | `type, ...vals` | 创建一个命名元组实例 |

### ChainMap（链映射）

| 函数 | 参数 | 描述 |
|------|------|------|
| `链映射/创建` | `...maps` | 创建链映射（多个字典串联） |
| `链映射/获取` | `cm, key, [default]` | 按顺序在多个字典中查找键 |
| `链映射/新增` | `cm, m` | 在链映射前部新增一个字典 |

### 示例

```racket
(require "std/collections.rkt")

;; Counter
(define c (计数器/创建 '("a" "b" "a" "c" "b" "b")))
(计数器/最多 c 2)  ;; → '(("b" . 3) ("a" . 2))

;; Deque
(define dq (双端队列/创建 1 2 3))
(define-values (dq2 item) (双端队列/右弹出 dq))
;; dq2 = '(1 2), item = 3

;; defaultdict
(define dd (默认字典/创建 (λ () 0)))
(默认字典/获取 dd "key")  ;; → 0（自动创建默认值）

;; namedtuple
(define Point (命名元组/创建 "Point" "x" "y"))
(define p (命名元组/新建 Point 3 4))
;; p = '#hash(("x" . 3) ("y" . 4))
```

```racket
;; 线程本地存储
(线程/设置本地值 "key" "value")
(线程/获取本地值 "key")  ;; → "value"
```
